VocaSnap 개인정보처리방침

최종 업데이트: 2026년 5월 7일

VocaSnap(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 본 방침을 통해 앱이 처리하는 정보를 투명하게 안내합니다.

1. 처리하는 정보

앱은 다음 정보를 사용자의 기기에 로컬로 저장합니다:

  • 사용자가 저장한 단어, 번역, 발음, 예문
  • 컬렉션 및 퀴즈 학습 결과

카메라로 촬영하거나 사진 라이브러리에서 선택한 이미지는 단어 인식을 위해 사용됩니다. 이미지는 Google ML Kit 기반 OCR, 언어 감지, 번역 기능에서 주로 기기 내에서 처리되며, VocaSnap 자체 서버로 전송되지 않습니다.

2. 정보 이용 목적

앱은 단어 인식, 번역, 단어장 저장, 컬렉션 관리, 퀴즈 학습, 광고 표시 기능을 제공하기 위해 위 정보를 사용합니다.

3. 사용하는 권한

  • 카메라: 단어 스캔을 위해 사용됩니다.
  • 사진 라이브러리: 갤러리에서 이미지를 선택해 단어를 스캔할 때 사용됩니다.
  • 인터넷: 광고 표시 및 단어 사전 API 조회에 사용됩니다.

4. 온디바이스 처리 및 외부 서비스

앱은 다음 제3자 서비스를 사용합니다:

  • Google ML Kit: OCR, 언어 감지, 번역 기능 제공을 위해 사용됩니다. 카메라/사진 이미지는 주로 기기 내에서 처리됩니다.
  • Free Dictionary API: 단어 발음 및 예문 조회를 위해 사용됩니다. 사용자가 조회한 단어 텍스트가 해당 API 서버로 전송될 수 있습니다.

5. 광고

본 앱은 Google AdMob을 통해 광고를 표시할 수 있습니다. 광고 제공, 부정 사용 방지, 분석 과정에서 AdMob SDK가 기기 식별자, 광고 관련 데이터, 앱 상호작용, 진단 정보 등을 처리할 수 있습니다. AdMob을 통한 정보 처리는 Google의 개인정보처리방침을 따릅니다.

6. 정보 보관 및 삭제

저장한 단어, 컬렉션, 퀴즈 결과는 사용자의 기기에만 저장됩니다. 앱을 삭제하면 저장된 로컬 데이터가 기기에서 삭제됩니다.

7. 아동 보호

본 앱은 만 14세 미만 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.

8. 방침 변경

본 개인정보처리방침은 앱 기능 또는 관련 법령 변경에 따라 수정될 수 있습니다.
